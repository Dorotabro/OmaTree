# Files removed from what windeployqt copied. One path (wildcards allowed) per
# line, relative to the staged application directory; '#' starts a comment.
#
# Every entry rests on evidence, not on guessing (see docs/PACKAGING.md):
#   * a traced run of the deployed application (QT_DEBUG_PLUGINS=1,
#     QML_IMPORT_TRACE=1, and the list of modules the process really loaded)
#     over a broad session: new note, Preview, Search, F1, Delete dialog, FILE
#     menu, Recovery, native Open and Save As dialogs, close;
#   * the application's own configuration: it selects the Basic Qt Quick
#     Controls style (cpp/controls_style.cpp) and imports only QtQuick,
#     QtQuick.Controls, QtQuick.Layouts and QtQuick.Dialogs;
#   * the dependency audit (verify-package.ps1), which fails if anything that
#     stays imports something removed here, and a second traced run on the
#     pruned tree.
# Nothing else is removed. In particular the whole Basic style, Templates,
# Layouts, Dialogs (with their QML fallback and Labs.FolderListModel), the
# Network and OpenGL libraries (omatree.exe links them) all stay.
